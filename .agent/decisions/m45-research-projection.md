## Recommendation

**Recommend: a closed, line-oriented recognizer IR, not an embedded general expression language.** JSON carries literal grammar data + a fixed pipeline; one monotone input cursor, finite ordered children, one exact-title dispatch. Output is `match(canonical_key)` or `no_match(reason)` for a valid program; malformed/unsupported IR is rejected when the bundle is verified, never executed opportunistically. The pipeline can be rendered as code without emitting executable code.

| operator | exact proposed v1 contract | grounds |
|---|---|---|
| `normalize_lines` | Require a string; map CRLF then CR to LF; split only LF; trim trailing ASCII space/tab; coalesce blank runs and discard leading/trailing blanks. Reject U+0000–001F except TAB/LF/CR, U+007F–009F, U+2028/U+2029 and U+D800–DFFF. No Unicode-property lookup. Keep all other characters unchanged. These equivalences belong to the sealed program version. | Q7–Q8: default whitespace/UCD behavior is broader than the wanted grammar; measured drift. Fixed passes only (Q1–Q2). |
| `choose_title` | Exact first-line literal → one branch + its fixed `document_type`. Branch titles unique; no match → no-match. No Unicode slug function. | Q3: literal/token boundaries suffice; Q5: broad title hypotheses need separating probes; Q7–Q8: `.lower()` drifts. |
| `sequence` | Execute a finite ordered array of consuming nodes once. No recursive reference, variable call, nested traversal, or branch fallthrough. Required node failure rejects the whole input. | Q1: totality alone permits expensive macros; structural progress + fixed program bound avoids that; Q6: do not silently omit bad nodes. |
| `label` | Consume exactly one line; partition once at literal ASCII `:`; trim ASCII space/tab around key; require exact declared key; ignore the remainder as value (colons in the remainder are data). Emit `{kind:'label', key:<recognized key>}`. Expected ordering/count is explicit in `sequence`, not inferred by a dictionary or sort. | Q2–Q3: literal partition + substring boundaries; Q4: preserve one result per consumed node; Q5: distinguish duplicate/order/first-versus-last-delimiter hypotheses. |
| `section` | Consume a blank separator, an exact declared `Heading:` with empty ASCII-trimmed suffix, then at least one body line up to blank/EOF; advance once per line, emit `{kind:'section', key:<recognized heading>}` only. Initial conservative body profile = nonblank text without `:` or the normalizer's forbidden controls; body values are explicitly opaque and excluded. A future profile allowing colon-bearing body text is a separately verified language change. | Q3: bounded region selection; Q6: every consumed region has a declared role; Q5: broader body grammars are distinguishable, not silently equivalent. |
| `emit_layout` | Construct fixed JSON fields `document_type` + ordered `structure` from the recognized title/entries. No implicit null, omission, deduplication, key sorting inside `structure`, floating-point arithmetic, coercion, or dynamic key names. Canonical JSON serialization follows Cement's existing contract. | Q4: fixed-key constructor is enough; wildcard omission and unordered object iteration are not appropriate here. |
| `end` | Require full normalized-input consumption before returning the key. Extra/missing/reordered/duplicated structural lines, wrong title, new block, unsupported codepoint or exceeded resource budget → no-match. No partial key escapes. | Q5–Q6: complete recognition + negative boundary examples; Q1: budget exhaustion is explicit rejection. |

**Cost contract (design inference, not a benchmark guarantee):** for fixed program size P, input codepoints N and output size O, the proposed monotone recognizer uses fixed normalization passes + one selected branch: O(N + P + O) time/space with append-and-finalize buffers; no growing-prefix concatenation. Validate caps for raw bytes/codepoints, IR nodes/depth/literal bytes, normalized lines, emitted entries and output bytes; debit consumed characters/nodes rather than relying on wall-clock time. Checked programs reference only original-input spans or shrinking subregions. JSON-shaping primitives should not expose arbitrary rescans or higher-order callbacks.

**Fixture fit, measured:** `.agent/decisions/m45-probe-projection.py` implements the proposed primitive behavior as a research sketch, not the production interpreter. Exact output: `"corpus_matched": 7`; 8 named value/normalization-positive probes; 17 named structure/type/Unicode-negative probes. CPython 3.11.15, 3.12.14, 3.13.14, 3.14.8 all rc 0; all three cross-version `cmp` calls rc 0. Outputs `captured output `projection-3.11.json` (regenerate: rerun the probe):1` through `projection-3.14.json:1` carry the complete key objects and case names. This proves the fixture claim, not equivalence over all OCR or performance bounds. Run: `uv run --no-project --python <3.11|3.12|3.13|3.14> python -I -B .agent/decisions/m45-probe-projection.py examples/hospital_ocr`.

**Full-consumption caveat / MAIN ruling:** source `examples/hospital_ocr/pipeline.py:195-197` says `entries.append(("section", key, "\n".join(lines[1:])))` then `continue`: every remaining line in that block is opaque body, not a separately validated structure. Probe output `"extra_body_colon_same_key": true` confirms legacy accepts an inserted `Extra: heading` inside Assessment without changing the key. Even the conservative profile must accept a new ordinary non-colon body sentence (positive probe `opaque_body_extension`): it has the same syntax as legitimate patient prose. Therefore “reject an unrecognized line” must mean outside the **declared grammar**, not detect semantically wrong text inside an allowed opaque field. The current spec is not demonstrably contradictory, but this term needs a contract definition. This proposal matches the seven fixture signatures while intentionally narrowing legacy behavior (title case, Unicode whitespace, colon-bearing section bodies); do not describe it as a drop-in reimplementation of `_parse_layout` over all inputs.

**Verification contract:** verify program/schema/cost limits first, then execute every confirmed raw input and compare the whole canonical key exactly (not one sample per key). A disagreement blocks the projection. Independently derive negative/positive probes from its declared equivalences: one-line insertion/deletion/reordering/duplication; empty or extra delimiter; header/body boundary movement; every supported newline form; each trimmed/preserved codepoint; title spelling/case; input/program/output size limits. Keep positive examples, negative grammar cases and expected-key disagreements distinct. Learned candidate + candidate-generated tests are not an independent oracle (Q5). Ledger-free and ledger-backed evaluators must call the same sealed interpreter/version, and the bundle must carry the exact projection identity together with its key/output entries; finite example verification does not prove semantic correctness of arbitrary future OCR.

**Deliberately exclude:** unrestricted CEL comprehensions, jq/JSONata recursion, user-defined functions, Python `eval`/`re`, backreferences/look-around, arbitrary regex syntax, dynamic code loading/callbacks, locale-dependent conversions, Unicode NFKC/casefold/default strip, numeric/date interpretation, generic string rewrite, structural sorting, ignored parse errors and extract-only wildcard filters. None is needed for the measured fixtures; the exclusions preserve a closed interpreter, fixed text semantics, full coverage and explainable costs (Q1–Q8). No third-party dependency is recommended. PROSE/FlashFill/FlashExtract inform operator design and verification, not a dependency or a proof that their whole languages meet this contract.

**Probe reproducibility:** `.agent/decisions/m45-probe-unicode.py`; run `uv run --no-project --python <version> python -I -B <absolute-script>` for each measured minor version. Rerun JSONL equals the initial inline probe byte-for-byte (`cmp` rc 0). No interpreter download was needed. No production source, spec, tests, gate, settings or tracked file was edited; no repository gate was run (research-only scope). WebSearch used 8/30; searches were targeted, not exhaustive. LangSec's `webtext` attempt failed certificate validation (rc 1); authenticated Neo returned its primary text without that failure. No other access gate blocked the cited evidence.
