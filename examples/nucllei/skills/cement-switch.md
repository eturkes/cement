# Cement の関数のオン・オフ

ユーザーが `/cement-switch` と送ったときだけ読み込まれる (説明が空なので、モデルからは見えない skill)。
学習済みの関数をオンにできるのはユーザーだけで、この skill はユーザーが選んだ変更を流すためにある。
`run_shell` で `/ext/bin/cement` を使う。`中止:` で止まったら、最後の行の `次の手:` に従う。

## 手順

1. `/ext/bin/cement status` を流し、操作ごとの版とスイッチを出力のまま見せる
2. `/cement-switch` に続く文 (または、この後のユーザーのメッセージ) が変更を 1 つ名指ししたら、それだけを流す:
   - オン (最新の版に追従する。学習で版が増えると新しい版が答える): `/ext/bin/cement switch <操作> follow`
   - 版 N に固定する (後の学習で版が増えても変わらない。前の版に戻すのもこれ): `/ext/bin/cement switch <操作> pin <N>`
   - オフ (その種類の頼みにはモデルが答える): `/ext/bin/cement switch <操作> off`

   名指しが無いか、どの変更か決まらないなら、選べる変更を並べて聞き、何も流さずにターンを終える
3. 中身を見たいと言われたら `/ext/bin/cement read <操作> <版>` を流して見せる (版を省くと最新の版)。
   2 つの版の違いは `/ext/bin/cement diff <操作> <前の版> <後の版>`
4. 変更したら、`switch` の出力をそのまま伝える

## 守ること

- ユーザーが選んでいない変更は流さない
- 学習 (`cement-learn`) はここでは流さない
