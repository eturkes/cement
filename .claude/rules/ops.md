- Worktrees: `.scratch/worktrees/<name>` on `wt/<name>`, MAIN alone writes the primary tree. Harvest reads `git diff --name-status main..wt/<name>` BEFORE choosing a verb: a pre-implementation base renders main's later commits as deletions, so `git merge --squash` is a silent revert — take the file (`git checkout wt/<name> -- <path>`, sha256-proven). That checkout STAGES the path ⇒ read `git status --porcelain` before any `--amend`; unstage with `git restore --source=HEAD~ --staged <path>`.
