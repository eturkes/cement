# Project operations

- Env: stdlib-only Python ≥3.11, `uv sync` builds `.venv`; every tool through `uv run` (bare `python` is absent from PATH → rc 127, which a patch step reports exactly like a live mutant surviving). Gate = `uv run python -m unittest discover -s tests -t .` (1010 tests, ~500 s, load-sensitive: `tests/test_source.py` drives real subprocesses + timeouts, so never run it beside a sweep) + `uv build`. No linter/type checker is configured (`Deferred` p01; a gate added mid-unit voids that unit's numbered gate pins). Example self-checks run only by hand ⇒ behavior worth protecting lives in `tests/` (`tests/test_hospital_ocr_example.py` puts the example dir on `sys.path`).
- Layout: `.agent/spec.md` = live state; `.agent/decisions/m<m>u<u>-*` = tracked contracts, ruled tables (`-verdicts.json`, `-attack.json`), `--check` patchers (`-rule-*.py`), validators + instruments — read on demand, exempt from the retired-name sweep; `.agent/archive/` = history (roadmap, polish `p<nn>` rows, memory, per-unit records). `.scratch/` is gitignored ⇒ a pointer into it is dead in every clone and on every other machine: copy the substance into tracked state when it is written. A tracked file never asserts the ABSENCE of gitignored or machine-local state (a worktree teammate sees its OWN empty `.scratch/`); write the property that travels — gitignored ⇒ no clone reruns it.
- History-walking gates: `test_migration_battery.py` D28 replays the full suite at EVERY revision in `6fb4d92..HEAD` touching `tests/`, `examples/` or `m3u6a1-surgery.py` ⇒ every commit touching those paths must be gate-green; red-to-green work rides a branch (`impl/<unit>`, tip tagged `archive/<unit>-impl`) and squashes into main as ONE green commit; a code seed uses `skipTest`, never `fail`.
- Tags: every worktree tip a record cites is tagged `archive/m<m>u<u>-<role>` before its `wt/` branch goes (`git tag -l 'archive/*'` = inventory; M3.4's five keep their `m3u4-*` names, local-only, unpublished). A local-only ref never carries a ruling — restate its grounds as measured facts in the tracked record.
- Worktrees: `.scratch/worktrees/<name>` on `wt/<name>`, MAIN alone writes the primary tree; contracts are COPIED into each worktree at dispatch (`cp` + `cmp`), since a worktree based at an earlier SHA cannot see an uncommitted record. Harvest reads `git diff --name-status main..wt/<name>` BEFORE choosing a verb: a pre-implementation base renders main's later commits as deletions, so `git merge --squash` is a silent revert — take the file (`git checkout wt/<name> -- <path>`, sha256-proven). That checkout STAGES the path ⇒ read `git status --porcelain` before any `--amend`; unstage with `git restore --source=HEAD~ --staged <path>`.
- Shared mutable resources = one named holder per wave: the primary tree, `__pycache__`, any running sweep (it patches `src/` in place — commit by explicit pathspec while one runs; after a kill, `git status --porcelain src/` + `git checkout -- src/`).
- Settings: `.claude/settings.local.json` machine-local; no project `.claude/settings.json` with a path-keyed `Read()` deny — it gates Bash by static command text and turns every `(cd <worktree> && …)` into a session-halting prompt under `bypassPermissions`. `.claude/commands/` stays absent (a project command masks the built-in `goal`).
- Commits: `<scope> (<trace>): <cause> → <fix>`, trace `(M<m>.<u>)` | `(M<m> block)` | `(M<m> plan)` | `(M<m> review)`; history `git log --grep "(M<m>[. ]"`. User drives remote; tags stay unpublished until the user pushes them.
- Read-and-conform-to set for every brief: gate above · oracles = `tests/`, `examples/hospital_ocr/` (demo + pinned transcript), `.agent/decisions/*-probes.json` corpora · scope sources = `.agent/spec.md`, README paragraph 1, `docs/architecture.md`, `docs/threat-model.md`, the unit's contract.
